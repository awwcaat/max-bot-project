# Сферум.Наставник

Бот в мессенджере МАХ, где школьники помогают друг другу с учёбой. Ученик просит помощь по теме, старшеклассник-наставник берёт заявку, они созваниваются и проводят занятие, а наставнику записываются часы, которые потом можно оформить как волонтёрские. Учитель-куратор следит за всем через веб-кабинет: видит низкие оценки и сорванные занятия, подтверждает или отклоняет часы и выгружает их в таблицу.

Команда «пвапвап», IT-Куб Южный, Южно-Сахалинск. Хакатон «Идея фикс», трек «Подземелье знаний».

## Из чего состоит проект

| Файл | За что отвечает |
|---|---|
| `bot.py` | Общение с людьми в МАХ: по одному обработчику на каждую команду и кнопку |
| `logic.py` | Данные и правила: заявки, занятия, оценки, часы; сохранение в `data.json` |
| `web.py` | Веб-кабинет куратора (удобен с телефона) |
| `requirements.txt` | Библиотеки Python |
| `Dockerfile` | Сборка Docker-образа |

## Подготовка: токен бота

Откройте `bot.py` и впишите токен бота МАХ в строку:

```python
TOKEN = "вставьте токен сюда"
```

Там же задаётся код куратора (`CURATOR_CODE = "1234"`) и порт кабинета (`WEB_PORT = 8080`).

## Запуск в Docker

Нужен установленный Docker. Команды выполняются в папке проекта.

Сборка образа:

```
docker build -t nastavnik .
```

Запуск контейнера:

```
docker run --name nastavnik -p 8080:8080 nastavnik
```

`-p 8080:8080` открывает веб-кабинет на вашем компьютере. После запуска в консоли появится «Бот запущен». Остановить можно через `Ctrl+C` или командой `docker stop nastavnik`, запустить снова — `docker start -a nastavnik`. Данные сохраняются, пока контейнер не удалён.

Веб-кабинет куратора: <http://localhost:8080/?key=1234>

## Запуск без Docker (через командную строку)

Нужен Python 3.10 или новее.

```
pip install -r requirements.txt
python bot.py
```

Одна команда запускает и бота, и веб-кабинет. Данные сохраняются в `data.json` рядом с `logic.py`, поэтому после перезапуска ничего не пропадает.

## Как проверить

Понадобятся два аккаунта МАХ: ученик и наставник. Куратором может быть третий аккаунт или один из этих двух. Найдите бота в МАХ и нажмите «Начать»: всё дальше делается кнопками.

1. **Наставник:** «🤝 Хочу помочь» → «Математика» → «🔔 Подписаться». Теперь новые заявки по математике будут приходить ему сами.
2. **Ученик:** «🙋 Мне нужна помощь» → «Математика» → пишет тему, например «дроби» → пишет комментарий или нажимает «Пропустить». Наставнику приходит карточка заявки.
3. **Наставник:** «✅ Помогу». Оба получают имя друг друга в виде ссылки на профиль МАХ, чтобы договориться о звонке.
4. **Наставник или ученик:** «▶️ Начать занятие», потом «⏹ Закончить». Минуты считает программа.
5. **Ученик:** ставит оценку ⭐1–5. Это подтверждает занятие, и наставнику записываются часы. Можно оставить комментарий, его увидит только куратор. Если занятия на самом деле не было, есть кнопка «❌ Занятия не было».
6. **Куратор:** пишет боту `/curator 1234`, в меню появляется «🛡 Кабинет куратора». Бот присылает сигналы о низких оценках и сорванных занятиях. В кабинете куратор подтверждает или отклоняет часы (с причиной, её увидит наставник) и скачивает CSV.

Описание всех кнопок — «ℹ️ Помощь» в меню бота.

## Правила, которые защищают от ошибок и накрутки

- Время занятия считает программа, а не человек.
- Подтверждает занятие ученик, а не сам наставник. Окончательно часы засчитывает куратор.
- Занятие короче `MIN_MINUTES` (в `logic.py`) не засчитывается. Для удобной проверки сейчас стоит 1 минута, в настоящей версии будет 20.
- У ученика не больше 3 заявок, ждущих наставника. У наставника не больше 3 занятий одновременно.
- Если двое нажали «Помогу» на одну заявку, второй получит «уже взял другой наставник».
- Оценки видит только куратор, дети друг у друга их не видят.
- Неверное или повторное нажатие кнопки не роняет бота: человек получает понятный ответ.

## Ограничения прототипа

- Данные хранятся в файле `data.json`. Для настоящей версии нужна база данных.
- Веб-кабинет открывается в браузере по коду в адресе. Чтобы он открывался прямо в МАХ как мини-приложение, нужен HTTPS-адрес, а для защиты — вход через аккаунт МАХ.
- Бот получает сообщения через Long Polling. Для постоянной работы нужны вебхуки по HTTPS.
- Класс ученика не учитывается: младший школьник может откликнуться на заявку старшего. В Сферуме возраст детей известен, но получить его может только сама платформа.
- Вместо интеграции с Добро.рф часы выгружаются в CSV.
